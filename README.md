# منوی کافه آتزوری (Caffè Azzurri)

همه اطلاعات منو (نام آیتم‌ها، قیمت‌ها، توضیحات، دسته‌بندی‌ها و طرح‌ها) در فایل **`items.json`** است.
صفحه منو (`index.html`) همیشه اطلاعات را از همین فایل می‌خواند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | صفحه منو برای مشتری‌ها |
| `designer.html` | ویرایشگر منو (افزودن و تغییر آیتم‌ها، قیمت‌ها و توضیحات) |
| `items.json` | اطلاعات منو |
| `art.js` | طرح‌های نقاشی‌شده آیتم‌ها |
| `assets/` | عکس‌های واقعی آیتم‌ها |
| `fonts/` | فونت‌ها |

## روش ساده: با ویرایشگر

1. `designer.html` را در مرورگر (ترجیحاً Chrome یا Edge) باز کنید.
   اگر `items.json` خودکار بارگذاری نشد، با دکمه **«باز کردن»** فایل `items.json` را انتخاب کنید.
2. روی **«ویرایش»** کنار هر آیتم بزنید.
3. متن **«توضیحات»** را بنویسید یا تغییر دهید و **«ثبت تغییرات»** را بزنید.
4. در آخر روی **«ذخیره»** بزنید.
   - در Chrome و Edge تغییرات مستقیم در فایل ذخیره می‌شود.
   - در مرورگرهای دیگر یک فایل `items.json` دانلود می‌شود؛ آن را جایگزین `items.json` کنار `index.html` کنید.

با همین ویرایشگر می‌توانید قیمت، نام، دسته‌بندی، موجود/ناموجود بودن، عکس و طرح هر آیتم را هم تغییر دهید یا آیتم جدید اضافه کنید.

## روش دستی: ویرایش مستقیم `items.json`

فایل را با یک ویرایشگر متن (مثلاً Notepad++ یا VS Code) باز کنید. هر آیتم این شکل است:

```json
{
  "id": 436192,
  "category": "گرم بر پایه اسپرسو",
  "title": "اسپرسو 100 عربیکا",
  "description": "اسپرسوی دبل از دانه‌های ۱۰۰٪ عربیکا.",
  "price": 249000,
  "image": "assets/MainImage_3f05ccc1.jpg",
  "available": true,
  "art": "espresso"
}
```

- **`description`**: توضیح آیتم. فقط وقتی مشتری روی آیتم می‌زند نمایش داده می‌شود. اگر نمی‌خواهید توضیحی باشد، آن را خالی بگذارید: `""`
- **`price`**: فقط عدد، بدون ویرگول (مثلاً `249000`).
- **`available`**: `true` یعنی موجود و `false` یعنی ناموجود.
- **`image`**: مسیر عکس واقعی. اگر عکس وجود داشته باشد، با زدن روی آیتم نمایش داده می‌شود؛ در خود منو همیشه طرح نقاشی‌شده دیده می‌شود.
- **`art`**: نام طرح آیتم (بهتر است از ویرایشگر انتخاب شود). اختیاری‌ها: `artSeed` (عدد، برای نسخه دیگری از همان طرح) و `artColor` (رنگ نوشیدنی، مثل `"#2a8ad6"`).

نکات مهم هنگام ویرایش دستی:

- متن‌ها باید داخل `" "` باشند. اگر داخل متن گیومه لازم دارید از `«»` استفاده کنید.
- بین آیتم‌ها ویرگول `,` لازم است، ولی بعد از آخرین آیتم نه.
- `id` هر آیتم باید یکتا باشد و بهتر است تغییر نکند.

اطلاعات بالای فایل هم قابل تغییر است: `restaurant` (نام کافه)، `latin` (نام لاتین)، `tagline` (جمله زیر نام)، `address` (آدرس پایین صفحه) و `currency` (واحد پول).

## اجرای منو

منو باید از طریق وب‌سرور باز شود (مثلاً روی هاست سایت). اگر `index.html` را مستقیم از روی فایل باز کنید، مرورگر اجازه خواندن `items.json` را نمی‌دهد.
برای امتحان روی کامپیوتر، در پوشه منو این دستور را اجرا کنید و آدرس `http://localhost:8000` را باز کنید:

```
python -m http.server 8000
```
